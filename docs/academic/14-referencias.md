## Criterio bibliográfico

Las referencias anteriores corresponden a documentación oficial de las herramientas que el repositorio declara o utiliza. Se mantienen en formato autor-fecha uniforme para que una persona revisora pueda identificar fuente, año de consulta, título y dirección. No se atribuyen a estas fuentes resultados de GarFit: se usan para fundamentar el funcionamiento esperado de Node.js, marcos, ORM, base de datos, autenticación y pruebas.

La documentación del código complementa estas referencias. En particular, los números de versión y scripts se toman de package.json; el modelo relacional se toma de schema.prisma; y el contrato HTTP se toma del OpenAPI generado. Esta distinción evita citar una guía general como evidencia de que una funcionalidad concreta fue implementada. La evidencia de ejecución está separada en docs/evidence.
