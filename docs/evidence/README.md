# Evidencia de verificación

Guarde evidencia reproducible de pruebas manuales y automatizadas: captura, salida de
comando, fecha ISO, hash del commit y entorno. No incluya secretos, tokens ni datos
personales. Use `AAAA-MM-DD_tipo_descripcion.ext`, por ejemplo
`2026-09-16_test-api-a1b2c3d.txt` o `2026-09-16_login-web-a1b2c3d.png`.

Una salida debe indicar el comando completo, resultado y commit. Las capturas deben
anotar ruta, escenario y resultado esperado. Enlácela desde TRACEABILITY o el capítulo
de resultados cuando exista.
