# Evidencia de pruebas — fase 4

Fecha: 2026-09-17  
Rama: fase-4-ia

## Resultado consolidado

Antes de la fase, lint, typecheck, test, build y la comprobación documental terminaron correctamente sobre el commit indicado por el equipo. La fase cerró con 238 pruebas: API 120, dominio 55, web 30, validación 14, movimientos 10 y cliente API 9. La cobertura de líneas registrada fue API 94.61 %, dominio 93.78 %, movimientos 100 %, validación 93.39 %, cliente API 79.45 % y web 10.71 %.

Los recorridos Playwright contra el proveedor simulado y sin Internet completaron cuatro flujos: atleta, entrenamiento, IA y WOD. La comprobación API verificó consentimiento requerido, datos insuficientes sin llamada al proveedor, análisis con evidencia resuelta, caché en solicitud idéntica y explicaciones de WOD y movimiento.

La semilla demo creó el atleta de demostración con cinco entrenamientos completados en los últimos 28 días y cinco marcas manuales. Se registró el aviso conocido de consultas concurrentes de `pg` como deuda, sin atribuirle un fallo de datos.

## Smoke de proveedor real

El comando de smoke de Gemini produjo: `SKIPPED — GEMINI_API_KEY not configured`. No hubo clave disponible; por ello la integración real permanece PENDIENTE. En móvil, typecheck, lint y exportación Android fueron correctos, pero no había dispositivo ni emulador para una validación real.
